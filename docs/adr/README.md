# Architecture Decision Records

Numbered records of decisions that constrain future work.

- One decision per file, `NNNN-kebab-title.md`.
- Status is one of `Proposed` / `Accepted` / `Superseded by NNNN`.
- Amend by writing a new ADR that supersedes the old one. Do not rewrite an accepted ADR in
  place; the point of the record is that you can see what we used to believe and why we
  stopped believing it.
- Claims about current behaviour must cite the file and symbol they were read from, so a
  future reader can check whether the ground has moved.
